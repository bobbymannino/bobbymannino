# RSS Feed

This blog now has an RSS feed! You can access it here:
[bobman.dev/blog.xml](/blog.xml).

Every post will be available on this and it will be automatically updated
whenever a post is updated or published.

There is a tiny Rust application I have build called
[GPUI RSS](https://github.com/bobbymannino/gpui-rss). You can use that to read
the feed, or if you want to learn more about GPUI RSS there is a
[blog post](/blog/gpui-rss) on that too.
